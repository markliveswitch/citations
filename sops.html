Standard procedures for citation building, auditing, and cleanup. Click a card to expand it. These are placeholders — replace with your actual process steps.

New client citation build
  1. Confirm NAP source-of-truth with the client (business name, address, phone, website URL — exact formatting).
  2. Add the confirmed NAP to the client roster page.
  3. Submit to primary directories first (Google Business Profile, Bing Places).
  4. Work through the secondary directory list, matching formatting exactly.
  5. Log each submission's status back on the roster.
Quarterly NAP audit
  1. Pull current listing data for each tracked directory per client.
  2. Compare against the roster's source-of-truth NAP.
  3. Flag any mismatch on the dashboard with directory + discrepancy noted.
  4. Prioritise fixes by directory authority / traffic impact.
Fixing a NAP mismatch
  1. Identify whether the fix requires directory-owner edit access or a claim/verification process.
  2. Submit correction through the directory's official edit flow — avoid third-party "fix it" services.
  3. Note expected turnaround time (varies by directory) on the dashboard.
  4. Re-check after the directory's typical processing window and update status.
Sending the claim/verification email to a client
  1. Check the directory links page for the directory's typical verification method. If it's marked "confirm on site," check the directory's current process yourself before emailing — don't guess or assume it's the same as last time.
  2. Pick the matching variant from the email templates page — email code, phone call, mail/postcard, or direct access grant.
  3. Fill in every merge field with the real client's details in your own email draft. Never paste real client details into the public site pages.
  4. Send the email, then log the site as "pending — awaiting client verification" on the dashboard.
  5. Once the client confirms (code received, access granted, etc.), complete the directory submission and move the status to live on the roster.
  6. If a client doesn't respond within about a week, send one follow-up before flagging it as stalled.
Duplicate listing removal
  1. Confirm the duplicate is genuinely the same business, not a second location.
  2. Use the directory's official duplicate-merge or removal request process.
  3. Keep the listing with more reviews / longer history as the primary where possible.
  4. Log the removal request date — some directories take weeks to process.
